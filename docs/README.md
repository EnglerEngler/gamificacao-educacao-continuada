## Entrega principal

O DOCX exige **um único registro arquitetural vivo** em [arquitetura/README.md](arquitetura/README.md). Esse é o documento principal: identificação da equipe, RF/RNF/RPC, matriz cumulativa, seis decisões, C4 final e síntese para AF.
